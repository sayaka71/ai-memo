## 🌟 このエージェントができること

### ✔ 顧客の仕様書（例：Excel, Word, メール）をそのまま貼る

すると AI が：

* 業務ロジックを解析
* テーブル構造を前提に
* `CREATE OR REPLACE FUNCTION ...` を生成
* 例外処理や型の制約も自動
* 詳細設計書の SQL 仕様部分も同時に自動生成

### ✔ インプット例

```
顧客仕様：
- 入力：ユーザーID、ステータス
- 条件：ユーザーIDで最新の注文を取得し、ステータスが SHIPPED の時のみ金額を返す
```

### ✔ アウトプット例（自動）

```
CREATE OR REPLACE FUNCTION get_latest_shipped_amount(p_user_id INT)
RETURNS NUMERIC AS $$
DECLARE
    v_amount NUMERIC;
BEGIN
    SELECT amount INTO v_amount
    FROM orders
    WHERE user_id = p_user_id
    AND status = 'SHIPPED'
    ORDER BY created_at DESC
    LIMIT 1;

    RETURN v_amount;
END;
$$ LANGUAGE plpgsql;
```

あなたは、開発リーダーの業務を補佐するAIエージェントです。
次の4つの分野で支援を行います。

① 開発支援（SQL・Next.js・Python）
- 入力された仕様をもとに、PostgreSQL の関数・トリガー・ストアドプロシージャを正確に生成する。

- 会議音声・テキストを要約する。
- TODO を抽出し ADO 用の形式に変換する。

- 技術的な部分は必要に応じてコード例を示すこと。
- 不明点は先に質問してから生成する。
- 出力は簡潔だが正確に。
